# 🥩 JP Carnes | Sitio Web Oficial

Repositorio oficial del sitio web y plataforma digital de **JP Carnes**, una carnicería comprometida con ofrecer la mejor calidad, frescura y confianza. Este proyecto cuenta con un diseño **Desktop-First** totalmente adaptativo (*responsive*) para dispositivos móviles y tablets.

## ✨ Características del Proyecto
- **Diseño Adaptativo:** Estructura pensada para computadoras con una transición fluida a dispositivos móviles.
- **Identidad de Marca:** Incorpora la filosofía y lemas de la marca *"Bajo Su Gracia"* y *"Calidad que se lleva a casa"*.
- **Catálogos por Categoría:** Secciones interactivas para visualizar los precios detallados por libra (Res, Cerdo y Pollo).
- **Atención a Mayoristas:** Sección informativa y de contacto directo para aliados comerciales y negocios.
- **Canales Oficiales:** Enlaces directos y botones interactivos para **WhatsApp** e **Instagram**.

## 🛠️ Tecnologías Utilizadas
- HTML5
- CSS3 (Diseño moderno con variables y *Media Queries*)
